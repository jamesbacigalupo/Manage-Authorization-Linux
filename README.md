\# Google Cybersecurity Certificate: Linux Permissions \& Access Control Portfolio Project



\## 📌 Project Overview

This project demonstrates the practical application of Linux command-line tools to manage system authorization and access controls. Completed as part of the \*\*Google Cybersecurity Professional Certificate\*\* program on Coursera, the objective was to modify file and directory permissions according to a fictional company's strict security requirements and verify the changes using the Bash shell interface.



\## 🏢 Scenario Context

\*Note: To respect Coursera's Honor Code, the raw instruction prompt files and proprietary background data provided by Google have been omitted. The configuration context is outlined below:\*

\* \*\*The Task:\*\* Audit existing file infrastructure and align user, group, and other permissions with organizational access policies.

\* \*\*Environment:\*\* Linux Bash Shell.

\* \*\*Business Use Case:\*\* Restricting unauthorized access to sensitive company directories while ensuring authorized staff retain proper read, write, and execute permissions.



\## 📂 Repository Structure

\* \*\*`Linux\_Permissions\_Management\_Report.pdf`\*\* - The final documentation detailing the security requirements, exact Bash commands executed, and screenshots verifying the updated permission states.



\## 🛡️ Skills Demonstrated

\* Linux System Administration \& Bash CLI Navigation

\* IAM (Identity and Access Management) Principle of Least Privilege

\* File \& Directory Security Auditing

\* Permission Management Tools (`chmod`, `ls -la`, `ls -l`)
